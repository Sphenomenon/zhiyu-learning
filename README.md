# 知屿课程空间

面向单讲师的知识付费课程网站，手机端优先。保留木纹、金色点缀、亮暗主题和中英切换；课程按章和小节组织，图文在本站阅读；需要视频的小节可单独附百度网盘链接，不在本站播放。

本地开发版已接入 Pages Functions + D1，包含服务端权限与内容管理。**正式短信/微信登录、在线支付和远端数据库尚未接入，不能直接用于真实收费运营。**

线上仍为之前的前端原型：https://zhiyu-learning.pages.dev

公开仓库：https://github.com/Sphenomenon/zhiyu-learning

## 本地运行

使用 Node.js 24 和 pnpm 11.22.0：

```bash
pnpm install --frozen-lockfile
pnpm dev
```

打开 `http://127.0.0.1:5173`。命令自动准备本地数据库，并启动前台和后端，不需要另外安装数据库服务。

进入个人中心，用 `admin@zhiyu.local` 测试管理员流程，用其他邮箱格式测试普通学员。验证码显示在本机表单里，**不发送邮件或短信，也不验证真实邮箱所有权**。生产环境默认关闭该测试登录方式。

详细操作、协作验收和目录说明见 [本地开发与验收](docs/local-development.md)。

## 已接通的开发流程

- 公开首页、课程和案例从数据库读取发布版内容。
- 会话、管理员角色和课程权限由服务端校验，不信任前端角色或 localStorage。
- 管理员编辑中英文首页/讲师、课程和案例，区分草稿保存与正式发布，检测并发编辑冲突。
- 课程支持章节、小节和图文块编辑、排序、预览、草稿与发布；小节插图可上传至私有对象存储。
- 每节百度网盘视频链接选填，可识别分享文字中的链接和提取码；留空即不显示影片入口。图文及影片都检查课程权限。
- 旧版整课网盘资料继续保留，记录领取时间和资源版本。
- 管理员生成一次性课程密钥，可指定一门或多门课程；同一码并发兑换只开通一个账号。
- 人工开通与撤销权限；撤权后重试旧密钥不会重新开通。
- 后台学员、密钥和收款记录支持服务端搜索与分页；学员可按角色筛选，密钥可按状态筛选。手机后台提供两行导航、完整表单和清晰的学员选择。
- 可记录明确确认过的线下收款，重复请求不会重复记账；未接入支付平台扣款或回调。
- 登录、兑换、资料领取、后台表单继续提供中英文界面，沿用现有亮暗配色。

课程和案例仍为公开演示内容。自动种子不包含网盘链接、真实学员、会话或可用密钥；旧的演示密钥 `ZHIYU-2026-DEMO` 不再有效。

## 检查

```bash
pnpm build
pnpm test
```

构建检查前台和服务端类型。测试包括独立临时 D1 的真实 Workers 集成检查，以及 DOM 表单交互检查；不会覆盖开发数据库。后端测试为验证验证码冷却时间，需要约半分钟。

GitHub Actions 执行构建和测试，不自动发布。源码协作不代表已更新线上站点；本版本尚未部署。
