# 知屿课程空间（前端原型）

一个针对知识付费授课人的手机端优先课程品牌网站，包含商务化公开首页、课程体系、独立案例墙、个人中心，以及面向技术小白的内容管理后台。

在线原型：https://zhiyu-learning.pages.dev

公开仓库：https://github.com/Sphenomenon/zhiyu-learning

当前仍是前端原型：登录、管理员和课程权限未接入服务端，展示的课程、讲师、案例及数据为演示内容。

公开仓库为 `Sphenomenon/zhiyu-learning`，默认分支为 `main`。仓库排除 `.wrangler/`、环境密钥、依赖、数据库、导出文件及构建产物；请勿提交真实网盘资料、用户信息或私有兑换码。

## 本地运行

建议使用 Node.js 24 LTS 和 pnpm 11.22.0；项目保留锁文件，CI 使用相同版本进行构建。

```bash
pnpm install --frozen-lockfile
pnpm dev
```

生产构建：

```bash
pnpm build
pnpm preview
```

## 原型功能

- 手机底部导航、全屏菜单和响应式课程卡片
- 顶部中英切换，覆盖公开页面、个人中心和课程权限流程，并记住用户选择
- 亮色／暗色主题切换，并记住用户选择
- 个人中心、学习进度、课程目录和权限列表
- 课程密钥兑换演示：`ZHIYU-2026-DEMO`
- 解锁后显示百度网盘课程入口与提取码（当前为演示数据）
- 微信/邮箱登录方式的前端状态
- 创作者内容工作台、学习者权限开关
- 独立内容后台：分别编辑中英文首页文案、管理课程、发布或隐藏案例、管理学员权限、生成密钥
- 后台修改的首页文案和案例会立即同步到公开网站（原型阶段使用浏览器本地数据）
- 访问状态暂存于浏览器 `localStorage`

## 上线前必须接入服务端

本项目当前是前端框架。正式密钥不可写在前端，也不能只依赖 `localStorage`。建议由服务端负责：

1. 主登录方式、会话与身份绑定（供应商及微信准入见登录方案，尚待选择）；
2. 支付回调和订单状态校验；
3. 密钥生成、哈希保存、一次性兑换与课程权限写入；
4. 管理员角色、权限操作日志和防越权校验；
5. 百度网盘链接与提取码仅在权限校验后返回，不能写入公开前端包。

视频使用百度网盘交付后，服务器只承担页面、登录、支付回调和权限查询，带宽成本会很低。低访问量版本可以从静态前端 + 轻量 API + 托管数据库起步。

现有 Cloudflare Pages 是 Direct Upload 项目，不能直接转换为原生 Git 集成。以后可通过 GitHub Actions 调用 Wrangler 更新这个项目；当前工作流仅执行前端构建。

需要注意：百度网盘链接和提取码一旦展示就可能被转发，网站无法做到真正的逐人防分享。可以通过定期更换链接、按购买批次分配链接、记录领取日志来降低传播风险。
