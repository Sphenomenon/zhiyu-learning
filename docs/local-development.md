# 本地开发与验收

更新日期：2026-09-09。本轮实现只在本地运行，未更新线上 Pages，也未创建远端数据库、短信账号或支付渠道。

## 一键启动

使用 Node.js 24 和 pnpm 11.22.0。仓库已包含依赖锁文件。

```bash
pnpm install --frozen-lockfile
pnpm dev
```

打开 `http://127.0.0.1:5173`。该命令会按顺序应用本地迁移、补充公开演示内容，然后启动 Vite 前台和位于 `127.0.0.1:8788` 的 Pages Functions。前台通过 `/api` 代理访问后端。

不用安装 MySQL、Redis、Docker 或独立短信工具。Wrangler 在本机模拟 D1，数据库保存在被 Git 忽略的 `.wrangler/state` 中。再次运行启动命令不会覆盖已有课程、草稿或用户数据。

开发命令明确指定 `vite.config.ts`，不会误用历史构建遗留的 `vite.config.js`。如端口已占用，请先停止占用端口的旧开发进程；启动器不会替你终止其他项目。

`pnpm dev:ui` 只启动前台，仍需可用的后端；它不再回退到演示权限。`pnpm preview` 也只是静态构建预览，不提供 API。

## 本机测试账号

进入“个人中心”，填写测试账号邮箱：

- `admin@zhiyu.local`：本机测试管理员。
- 其他邮箱格式，例如 `learner@example.com`：普通测试学员。

点击获取验证码后，验证码直接显示在本机表单上，5 分钟内有效。这里不验证邮箱所有权，也不发送邮件或短信，不能用于真实用户登录。验证码单次使用，最多尝试 5 次，同一身份 30 秒内不能重复获取。

管理员身份由本机启动配置指定，前端不能选择角色。只有同时满足 `AUTH_MODE=local`、HTTP 协议和 loopback 主机地址时，测试登录才启用。仓库的 Wrangler 默认配置为 `AUTH_MODE=disabled`；部署到 HTTPS 站点时，即使误设为 local，也不会开放测试验证码接口。

生产环境必须使用独立数据库，不能把本地测试用户、会话或假身份导入正式用户库。手机号/微信的正式身份、绑定和找回流程尚未实现。

## 手动走通一轮

1. 用测试学员登录一次，创建学员账号，随后退出。
2. 用测试管理员登录，从个人中心进入“内容管理后台”。
3. 在“课程管理”编辑课程。先保存草稿，检查公开课程尚未变化，再点击“发布到网站”。中文和英文分开编辑；课程和案例不提供英文时显示中文。首页双语为必填项。
4. 在课程的“交付资料”填入你有权使用的百度网盘链接及 4 位提取码。资料立即保存，独立于公开介绍和草稿；本地演示种子不包含网盘链接。
5. 在“课程密钥”选择一门或多门课程，生成密钥并复制。完整密钥只在这一次响应中显示，数据库只存哈希和尾号。
6. 用另一个浏览器或无痕窗口登录学员账号，兑换密钥并领取资料。不要将真实资料放入自动化测试或提交到公共仓库。
7. 管理员到“学员权限”撤销这门课程，再让学员重新领取资料，应收到无权限提示。重试已经兑换过的密钥不会恢复被撤销的权限。

后台可以直接开通权限，并填写操作原因。仅在勾选“我确认已在线下收到这笔款项”并填写金额后，才创建人工收款记录。该记录不是支付平台回执，也不会发起扣款。操作编号保证同一请求重试不会重复记账。

后台编辑带版本校验。如果两位协作者同时编辑，后保存的一方会收到版本冲突提示，编辑内容会保留在表单中；复制需要保留的内容后，关闭编辑器、刷新列表再编辑。

课程下架会从公开目录移除，但不取消已有学员权限；下架后的个人中心只显示课程资料占位标题，不读取工作草稿。权限取消请使用“学员权限”。

## 自动化检查

```bash
pnpm build
pnpm test
```

- `test:backend`：建立独立临时 D1，在真实本地 Workers 运行时中检查会话、重复验证、CSRF、资料隔离、并发兑换、撤权、草稿发布、版本冲突、人工收款幂等和第二次登录的账号一致性。
- `test:ui`：使用 DOM 环境检查登录、兑换失败、管理员入口、私有资料拒绝、草稿/发布以及主题和语言切换。
- 后端测试为验证真实的重复获取限制，会等待约 31 秒。测试结束清理的是临时测试目录，不是开发数据库。
- UI 测试不是手机或桌面浏览器的像素截图验收。实际手机布局、系统键盘和网盘跳转仍需真机检查。

GitHub Actions 运行构建和这两组测试，不自动部署。

## 代码入口

| 位置 | 用途 |
| --- | --- |
| `functions/api/[[path]].ts` | Pages Functions 入口 |
| `server/router.ts` | API 路由与统一错误处理 |
| `server/auth.ts` | 测试身份适配、会话、角色检查 |
| `server/access.ts` | 密钥、权限、私有资料、人工收款 |
| `server/content.ts` | 公开字段校验、双语内容、草稿与发布 |
| `migrations/` | 数据库结构、原子兑换触发器、幂等操作记录 |
| `src/Account.tsx` | 学员登录、兑换、资料领取 |
| `src/Admin.tsx` | 内容编辑与运营管理表单 |
| `src/AppBusiness.tsx` | 保留现有品牌风格的公开页面与导航 |
| `src/catalog.ts` / `src/data.ts` | 公开演示种子，不含私有资料 |

业务状态不再读取历史 `zhiyu-access`、`zhiyu-content` 或 `zhiyu-stories` 的 localStorage。原型中的本机修改不会自动迁入数据库。旧键值无需删除；当前仅使用 localStorage 记住主题与语言。
