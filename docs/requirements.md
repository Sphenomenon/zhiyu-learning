# 产品需求基线

更新日期：2026-09-09。已确认项来自需求讨论；“建议”和“待确认”尚未视为产品决定。

## 已确认

- 面向一位知识付费讲师，由讲师维护课程与内容，优先优化手机端体验。
- 已有 React、TypeScript、Vite 前端，部署于 https://zhiyu-learning.pages.dev 。
- 网站公开区域保留首页、课程体系、案例墙、讲师介绍。学习、资源和账号设置集中在个人中心。
- 保留中英切换、亮暗主题，以及现有务实商务风、吉他图片、木纹与金色材质。
- 课程通过百度网盘链接和提取码交付，不在本站托管或播放付费视频。
- 用户付费获得权限，也需要兑换码开通方式；订单与权限必须持久化。
- 提供适合技术小白的内容后台，能编辑首页、讲师介绍、课程、案例、网盘资料及用户权限。
- 服务器预算希望控制在约人民币 300 元/年。该数字是预算，不是年用户数；访问量尚未给出。
- 公开源码仓库为 https://github.com/Sphenomenon/zhiyu-learning ，已按用户要求通过浏览器创建。

## 当前实现的边界

| 区域 | 已有内容 | 还需补齐 |
| --- | --- | --- |
| 前台 | 页面、导航、主题、语言、演示课程和案例 | 从服务端读取已发布内容 |
| 登录 | 账号与微信/邮箱绑定的展示 | 身份验证、会话、绑定与找回 |
| 课程权限 | localStorage 记录与演示兑换码 | 服务端一次性兑换、按用户校验 |
| 后台 | 编辑弹窗、部分本地存储、演示操作 | 管理员鉴权、数据库保存、跨设备同步 |
| 资料 | 演示网盘入口与提取码 | 私有保存、权限校验后返回 |
| 进度 | 示例数字与状态 | 定义手动学习进度；无法追踪网盘内实际播放 |

入口为 `src/main.tsx` → `src/AppBusiness.tsx` 和 `src/business.css`。`src/App.tsx` 是保留的早期原型，当前未被入口引用。

## 第一版建议

1. 单讲师、单站点，管理员与学员两类角色。
2. 先选一个主登录方式；当前建议考察支持个人主体的短信认证服务，微信绑定保留扩展位置。
3. 如果暂时没有支付商户资质，采用人工确认收款后发码或直接开通，记录操作者和原因。
4. 一码绑定一个账号；可关联一门或一组课程，是否长期有效与套餐规则待确认。
5. 后台提供表单、封面预览、草稿、发布/下架和保存提示；正常编辑不需要修改代码或重新部署。
6. 案例默认由管理员审核发布。学员直接投稿可作为后续功能。

## 待确认

- 运营主体是个人、个体工商户还是公司；平台账号、域名和收款最终归谁持有。
- 第一版人工收款还是站内自动支付。
- 主登录方式、是否面向境外手机号、预计每月验证码量。
- 最终课程是否为吉他教学；现有图片是吉他风格，但课程与讲师文案仍为知识管理示例。
- 购买按单课、合集还是会员；永久权限或有效期；退款后的权限处理。
- 独立域名是否已有、是否需要大陆服务器，以及内容实际服务类目。
- 案例是否允许学员投稿；学习进度是否需要用户手动标记。

## 第一阶段验收

- 同一账号在两个浏览器登录后，已购课程一致。
- 未登录或未购买的请求不能取得真实网盘链接和提取码。
- 同一兑换码并发兑换时仅一次成功，同账号重试不会重复开通。
- 学员不能调用后台接口；关闭权限后不能再次领取资料。
- 管理员保存并发布的内容可被另一台设备访问；草稿不会出现在公开接口。
- 账号绑定不会创建重复购买记录；不能解绑账号最后一种可用登录方式。
- 公共源码、前端构建、公开 API 均不包含真实兑换码、私有资料或授权密钥。
