# 编辑章节、图文与视频

课程的结构是“课程 → 章 → 小节”。文字、插图在网站里阅读，百度网盘只存放视频；每节可单独决定是否提供视频。

## 老师如何编辑

1. 登录管理员账号，从个人中心打开“内容管理后台”。
2. 在“课程管理”新建或编辑课程介绍。这里的标题、简介和封面属于公开内容。
3. 打开该课程的“章节与小节”。先“新增章”并填写章节名称，再“新增小节”。
4. 给小节命名，按需“添加段落”“添加标题”“添加图片”。上下箭头可以调整章、小节和图文块的顺序。
5. 插图可以“从设备上传图片”，支持 JPG、PNG、WebP，每张最多 5 MB；图片说明也可编辑。上传图片随课程权限保护。也可以填写现有 `/images/` 地址或 HTTPS 图片地址，这些外部/公共图片本身不受本站权限保护。
6. 需要视频时，在“影片链接（选填）”粘贴百度网盘分享文字或链接，系统会识别提取码。可补充视频说明。无需视频时留空，或点击“移除本节影片”，学员就只看到图文。
7. “预览本节”检查阅读效果。“保存章节草稿”只保存工作内容；“发布章节”后，有权限的学员才能看到这一版内容。课程介绍和章节分别发布，新建课程还需发布公开介绍。

英文内容可切换到 English 编辑，留空时显示对应中文；插图与视频共用。发布后前台的学习单元数自动采用已发布小节总数。

## 学员如何阅读

在“个人中心 → 我的课程与资料 → 进入课程”，或在课程页点击“进入我的课程”。电脑左侧显示目录，手机可“展开目录”。点击小节或使用“上一小节 / 下一小节”切换，地址可直接定位到对应小节。

没有视频的小节不显示影片卡片、播放器或空链接。有视频时，图文后会出现“本节影片”、可复制的提取码及百度网盘入口。本站不会记录网盘里的观看进度。

未开通的访客只能看已发布目录；正文、上传插图和视频链接均由服务端核验课程权限。权限撤销或过期后，重新访问、刷新或回到页面会重新检查权限。

## 保存与暂停发布

- 草稿可包含尚未写完的内容；发布要求章节和小节具备名称，每章至少一小节，每节至少有一块有效图文或一个视频链接。
- 每课程最多 50 章、500 小节，每章最多 100 小节，每小节最多 100 个图文块；章节 JSON 请求最大 1 MB，图片单独上传，不放进正文 JSON。
- 关闭未保存的编辑器会提示；发生版本冲突时，输入保留，请先复制需要保留的内容，再关闭并重新打开编辑器合并修改。
- “暂停发布”隐藏整门课程的章节正文与影片，保留草稿。公开课程下架与学员撤权是独立操作。
- 删除图片块只影响草稿，发布后才影响学员；对象存储里的文件暂时保留，不会自动永久删除。
- 旧版“整课影片”入口为已有资料保留。新内容放入各小节，不会把整课链接自动拆分成多个视频。

## 本机与正式环境

`pnpm dev` 自动应用 `0004_course_curricula.sql`，并使用本机 D1 / R2。代码仓库不包含真实课程正文、网盘链接或上传图片。当前本机另有“章节图文演示”供操作验收，不属于生产课程，未配置真实影片。

正式环境需要应用迁移、绑定私有 R2 `COURSE_IMAGES` 并完成正式登录配置。不要开放图片桶的公共访问，也不要把本机测试身份和演示数据库导入生产环境。
